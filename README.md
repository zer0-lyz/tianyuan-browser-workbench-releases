# Tianyuan Browser Workbench Releases

天源浏览器工作台公开发行仓库。

本仓库只提供：

- Windows x64 安装包；
- macOS Apple Silicon 安装包；
- SHA-256 校验文件；
- `update-manifest.json`；
- GitHub Release 更新说明。

源码保存在私有开发仓库，本仓库不保存 MCP token、Cookie、Authorization、密码、验证码或用户运行数据。

## 安装

请进入 Releases 下载与当前操作系统匹配的 ZIP，解压后运行包内安装程序。

- Windows：运行 `安装.cmd`；
- macOS：运行 `安装.command`。

安装或更新完成后，请在 Chrome 或 Edge 扩展管理页重新加载本机扩展目录。
